# Feature requests

Feature requests are reviewed by the product team every two weeks. Popular requests are
grouped into themes and published on the public roadmap at the start of each quarter.

## How to request a feature

Describe the problem you are trying to solve rather than the solution, and include how often
it affects your team. Requests with a clear use case are prioritised faster.

## Dark mode and accessibility

Dark mode is on the roadmap for the second half of the year. Accessibility fixes are treated
as bugs, not feature requests, and are scheduled within the current sprint.
