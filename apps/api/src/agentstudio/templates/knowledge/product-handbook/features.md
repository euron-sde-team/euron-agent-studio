# Features

## Ticket triage

AI-assisted triage classifies incoming tickets by topic and urgency, routes them to the right
team and suggests replies from the help center. Teams typically cut first response times by
40 percent in the first month.

## Automations

Automations run on ticket events, schedules and webhooks. They can update fields, notify Slack
channels, call external APIs and hand off to a human for approval.

## Reporting

Dashboards cover volume, response times, satisfaction and agent workload. Reports can be
exported to CSV or sent to a data warehouse daily.
